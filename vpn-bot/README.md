# Vasya VPN Bot — Telegram-бот VPN-сервиса на серверах h1cloud

Готовый Telegram-бот для продажи VPN-подписок: **aiogram 3 + SQLite + панель H1/VLESS (h1cloud) + RollyPay**.

Вам не нужен отдельный VPS: пакет **«Свой VPN»** (https://my.h1cloud.net/shop/bundle) уже включает
серверы в 5 странах с панелью H1/VLESS. Бот подключается к их API и сам создаёт/продлевает
ключи покупателям.

## Возможности

**Для пользователей:**
- 🚀 Подписка: пробный период, тарифы 1/3/6/12 мес, продление (срок суммируется)
- 🔑 Автоматическая выдача VLESS-ключей на **всех** купленных странах: по кнопке на страну — ссылка подписки + QR
- 👤 Профиль: статус и срок подписки, кнопка «Мой VPN-ключ»
- 👥 Реферальная программа: бонусные дни рефереру и приглашённому за первую оплату
- 🛟 Поддержка: тикеты админам, ответ — reply или `/reply`
- 🔔 Уведомления: за 3 дня, за 1 день и при истечении подписки
- ❓ Инструкция (Happ, v2rayNG, Streisand, V2Box, Hiddify)

**Для админа:** `/admin`, `/stats`, `/nodes` (проверка всех стран), `/find`, `/grant`, `/ban`, `/unban`, `/broadcast`, `/reply`, `/close`, ответ reply-сообщением.

**Платежи RollyPay:** тройное идемпотентное подтверждение — вебхук с HMAC-подписью, кнопка «Я оплатил», фоновый опрос.

## Установка

### 1. Купите пакет «Свой VPN» на h1cloud
1. https://my.h1cloud.net/shop/bundle → например «Пакет 5 стран · 100 Мбит/с».
2. Отметьте 5 стран (сейчас: Эстония, Турция, Швейцария, Грузия, Швеция, Испания, Германия, Беларусь и др.).
3. После оплаты — в «Моих услугах» появятся 5 серверов. Панель оставляйте **H1/VLESS** (по умолчанию, бесплатно).

### 2. Возьмите данные каждой ноды
Для каждой страны, со страницы сервера в кабинете (блок «Панель H1/VLESS»):
- **URL API** — вида `https://IP:25626/api`
- **API-токен** — команда `vpn api token` на ноде
- **Адрес подписки** — вида `https://IP:25627/sub/{uuid}`

### 3. Бот в Telegram
1. `@BotFather` → `/newbot` → `BOT_TOKEN`; ваш ID (`@userinfobot`) → `ADMIN_IDS`.
2. `/setbotcommands` → отправьте: `start - Главное меню`, `admin - Админ-панель`, `stats - Статистика`.

### 4. Настройте `.env`
Скопируйте `.env.example` → `.env`:
```env
BOT_TOKEN=...
ADMIN_IDS=...
H1_NODES=Германия|https://1.2.3.4:25626/api|tok1|https://1.2.3.4:25627/sub/{uuid};Турция|https://5.6.7.8:25626/api|tok2|https://5.6.7.8:25627/sub/{uuid};...
H1_VERIFY_SSL=false
ROLLYPAY_API_KEY=rpk_live_...
ROLLYPAY_SIGNING_SECRET=...
```
Тарифы/цены — в `config.py` (список `PLANS`), пробный период и рефералка — в `.env`.

### 5. bothost
1. Загрузите папку `vpn-bot`, зависимости — `requirements.txt`, точка входа — `main.py`.
2. Бот открывает порт `WEBHOOK_PORT` (8080) для вебхуков RollyPay. Если bothost даёт внешний адрес — укажите в `PUBLIC_URL` и пропишите в кабинете RollyPay `callback_url = PUBLIC_URL/rollypay/callback`. Если нельзя — оплата подтвердится кнопкой «Я оплатил» и фоновым опросом (до 5 минут).

### 6. RollyPay
1. Заявка на https://rollypay.io → получите `api_key` и `signing_secret`.
2. Для тестов: `ROLLYPAY_TEST_MODE=true` — оплата проверяется без денег.
3. В кабинете задайте `callback_url` (см. выше) и включите нужные способы оплаты (СБП, карта, крипта).

## Как это работает

| Действие бота | Вызов API ноды H1/VLESS |
|---|---|
| Покупка / пробник | `POST /create` (если имя занято — `PATCH /edit`) |
| Продление | `PATCH /edit` — `days` прибавляется к сроку |
| Ссылки по странам | `GET /clients/{name}` → uuid → `https://IP:25627/sub/{uuid}` |
| Проверка серверов | `GET /health` (команда `/nodes`) |

Имя клиента на каждой ноде — `tg<telegram_id>`. Бот создаёт пользователя на всех купленных
нодах сразу, поэтому подписка покрывает все страны пакета. Нода сама следит за сроком и
лимитом трафика/устройств.

## Команды админа

| Команда | Описание |
|---|---|
| `/admin` | справка |
| `/stats` | пользователи, подписки, выручка |
| `/nodes` | доступность всех купленных стран |
| `/find <id>` | карточка пользователя |
| `/grant <id> <дней> [гб]` | выдать/продлить подписку |
| `/ban <id>` / `/unban <id>` | блокировка (+ ban на нодах) |
| `/broadcast <текст>` | рассылка |
| `/reply <тикет> <текст>`, `/close <тикет>` | тикеты |
| reply на сообщение пользователя | мгновенный ответ |

## Частые вопросы

- **Оплата прошла, бот молчит?** Сработает кнопка «Я оплатил» или фоновый опрос; вебхук ускоряет до секунд.
- **Одна нода легла?** Бот продолжит работать с остальными, в `/nodes` видно состояние; ссылки выдаются живыми с нод при каждом запросе.
- **Расширить пакет?** Купите ещё страны, добавьте их в `H1_NODES` — бот начнёт выдавать и их.
- **Несколько VPN-серверов вне h1cloud (Marzban/3x-ui)?** Можно добавить: структура клиента изолирована в `h1cloud.py`.
